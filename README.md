# 🐾 PetHealthAssistant

**PetHealthAssistant** is an AI-powered virtual vet application built with **Streamlit** and **Gemini Pro** to help pet owners track, manage, and understand their pet's health — right from uploading images to managing vaccines and getting diet suggestions. Whether you're a dog lover, cat parent, or have a rabbit or bird buddy — this assistant has your back!

---

## 🚀 Features

### 1️⃣ Welcome Page
A friendly landing page introducing users to the Pet Health Assistant. This screen sets the tone and invites users to explore the app's features.

### 2️⃣ Pet Details & Image Analysis
- Upload a photo of your pet 🐶🐱
- Describe symptoms like "not eating," "sluggish," or "vomiting"
- AI (Gemini Pro) provides:
  - Visual health insights (e.g., coat, eyes, posture)
  - Possible causes of described symptoms
  - Home care tips and next steps

### 3️⃣ Pet Vaccination Tracker
- Choose pet type (Dog, Cat, Rabbit)
- View standard vaccine schedules
- Add/update vaccination status
- Automatically calculates next due dates based on vaccine intervals

### 4️⃣ Pet Diet Recommendation Based on Health Conditions
- Get tailored diet suggestions based on your pet’s species, age, and current health issues
- Helps with conditions like obesity, allergies, and sensitive digestion
- AI provides home-friendly feeding advice and food options

### 5️⃣ Deworming Assistant
- Enter last deworming date
- Automatically calculates and reminds you of the next due date
- Educational info on why deworming is crucial for different pets

---

## 💻 Tech Stack

- **Frontend**: Streamlit
- **AI Model**: Gemini 1.5 Flash via `google.generativeai`
- **Image Processing**: PIL (Python Imaging Library)
- **Date & Time Handling**: `datetime` module

## 📦 Installation & Usage

```bash
# 1. Clone the repository
git clone https://github.com/yourusername/PetHealthAssistant.git

# 2. Navigate into the project folder
cd PetHealthAssistant

# 3. Install dependencies
pip install -r requirements.txt

# 4. Run the app
streamlit run app.py
```

> 🧠 Don't forget to add your own Google Gemini API key in the appropriate section.
